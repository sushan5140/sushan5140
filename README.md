### Questions I keep coming back to

- When does a better average metric hide a worse failure mode?
- Can uncertainty guarantees remain reliable for individual subjects?
- How should retrieval systems behave when the “closest” context is still wrong?
- Can AI systems expose limitations and provenance instead of pretending every output is equally trustworthy?
